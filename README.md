The aim of this project was to develop biological data analysis skills in python using libraries for data wrangling, analysis, and visualization. 

Libraries used in this program include Biopython, Pandas, Seaborn, Matplotlib, and Ete 3. 

Metadata generation for this project is described in the Github repository [Link](https://github.com/TheWrightonLab/Methanotroph_rpS3Analyses_SmithWrighton2018)
